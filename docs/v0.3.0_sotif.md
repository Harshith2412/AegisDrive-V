# Intended-functionality and scenario assurance study

This project-specific analysis is inspired by ISO 21448's intended-functionality scope;
no normative requirements, conformance, certification or new ASIL allocation are claimed.
The public [ISO scope](https://www.iso.org/standard/77490.html) is contextual, not an adopted
compliance checklist. Hardware/software malfunction is distinguished from performance
insufficiency without faults; malicious manipulation belongs to cybersecurity analysis.

## Intended function and ODD

Enabled longitudinal AEB assists an inattentive driver approaching one relevant in-path
passenger vehicle on a flat straight road. New braking initiates only at 10–80 km/h.
Existing interventions may continue below 10 km/h; the warning-to-braking ODD defect found
in audit is corrected. Dry-road nominal ODD remains unchanged; adverse weather/friction
experiments do not expand it. No pedestrians, curved paths, grade, cut-ins, actual vision
images, target classification or real sensor cross-calibration are represented.

The camera samples every 50 ms by default, delivers after 80 ms, range limit 120 m,
half-angle FOV 30 degrees, independent seeded range/rate noise 0.4 m / 0.2 m/s,
detection probability 0.98 and assumed confidence 0.85. Visibility and occlusion scale
its detection probability and positive-detection confidence. Nondetection does not prove
free space. Camera has unavailable/frozen/bias/ghost cases and preserves acquisition time.
These are declared toy-model assumptions, not empirically fitted camera specifications.

Fusion validates source health, sampling age 0–150 ms, finite/plausible values and confidence
>=0.65. It predicts delayed ranges to the current time using the measured range rate;
no current/future truth is read by fusion. If both report targets, gates are 3 m and 2 m/s;
within gates, confidence-weighted averaging is used. Confidence is not a Bayesian posterior.
Outside gates the result is unavailable, with no unsupported selection of a winner. One
healthy accepted source supports an explicit single-source degraded perception mode.
A target from one source is retained when the other has no detection. This preserves
recall but admits isolated ghosts; the negative false-intervention experiment is retained.
Requiring corroboration would reject those ghosts at the cost of misses during real
single-source operation. That tradeoff is deliberately unresolved, not hidden by tests.

## Classification and insufficiency matrix

| Trigger / scenario | Class | Insufficiency / hazard | Mitigation examined | Residual uncertainty |
|---|---|---|---|---|
| Fog/reduced visibility | SOTIF | Camera recall/confidence falls; radar may also degrade in reality | Radar fallback; visibility sweep | Toy visibility factor, no validated adverse-weather transfer function |
| Partial occlusion | SOTIF | Missed object and unstable detection | Single-source union policy, sustained brake release | No temporal tracker or occluder geometry; camera-only misses can cause release |
| Radar ambiguity/plausible range bias | SOTIF if measurement ambiguity; fault if a component defect | Delayed/missed brake or false brake | Disagreement gates | Cannot choose correct sensor; consistent bias passes gates |
| Camera false negative | SOTIF | Relevant target undetected | Retain radar target; camera-only comparison | Complete common nondetection unmitigated |
| Radar/camera ghost | SOTIF for perception ambiguity | Unnecessary braking and rear-traffic risk | Confidence/plausibility/gates tested | Isolated plausible ghost and correlated ghosts can cause braking |
| Difficult disagreement | SOTIF or fault, according to cause | Rejecting both can miss a real obstacle | Explicit DISAGREEMENT/unavailable mode | No independently justified winning source; collision may follow |
| Frozen radar/camera | E/E fault model | Stale data -> unavailable/missed braking | Acquisition timestamps; healthy-source fallback | Shared scheduling/time/power not independent |
| Both channels frozen/unavailable | Correlated E/E fault model | AEB unavailable | Alert, no blind initiation | Collision remains; no third source |
| Low adhesion | SOTIF / environment | Available mu*g below 4 m/s² planning assumption | Parameter-diverse friction study, achieved-decel mismatch | IMU diagnostic cannot create grip; no friction estimator |
| Speed crosses activation bound | ODD boundary | Previously WARNING bypassed speed gate | C++ transition tests, guard correction | Disabling assistance above 80 km/h still leaves threat unmitigated |
| Lost/delayed/duplicated requests | Communication fault | Demand absent, old or rejected | Independent backup E2E receiver and timing study | Shared ECU/actuator/power; bounded counters not authenticated freshness |
| Forged frames, recomputed CRC | Cybersecurity | Accepted malicious demand | Existing characterization retained | No authentication; not labeled a SOTIF mitigation |

No fault rates or exposure frequencies are fabricated. Cause classification depends on
whether the observed bias is intended-function insufficiency, physical malfunction or attack;
the same numerical injection is not evidence that these causes are equivalent.

## Known/unknown coverage and validation argument

The case manifest is fixed before execution. Original six scenarios are repeated with
radar-only, camera-only, combined and combined+backup configurations. Eighteen explicit
fault/SOTIF cases retain failures and false interventions. Development parameter samples
(48) and held-out samples (120) use separate master seeds fixed in source. Samples vary
speed, initial gap, friction, camera latency/visibility/occlusion/detection probability,
radar latency/noise and bus delay. They are meaningful diversity beyond repeated sensor
noise, but still a narrow single-stationary-target population with an artificial uniform
parameter distribution. The hold-out set is not used to tune thresholds after outcomes.

Known safe/unsafe means observed modeled outcomes, not universal regions. Experiments
identify known unsafe members (unrecoverable actuator faults, correlated errors, low grip,
short distance, ODD exclusion, ghosts). Unknown safe and unknown unsafe regions remain
unquantified. Road geometry, image-domain limitations, multiobject association, dynamics
and driver/follower reactions are major untested spaces. A single numeric coverage
percentage for the scenario universe would be invented, so none is reported.

For fixed noise-only scenario repeats, Wilson intervals describe only the assumed noise
model. For sampled parameter trials, intervals are conditional on the declared artificial
sampling distribution. Designed grids/case mixtures are reported descriptively, not as
estimated real-world collision probability. See results/v0.3.0/evaluation.md for actual
outcomes, missed-detection cycle counts, false interventions and missing measurements.
