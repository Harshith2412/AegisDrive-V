Historical HARA, goals, FSC/FSR, TSC/TSR, FMEA/FTA and provisional S/E/C/ASIL rationale are
retained in docs/v0.2.0_safety.md; later sensing/actuation concepts in v0.3.0_fault_containment.md
and SOTIF/security artifacts remain supporting evidence. This review does not convert those
working hypotheses into substantiated ASILs, formal standard-derived requirements or
certification. The lifecycle audit flags incomplete explicit derivation and underspecified
avoidance wording rather than silently treating all passing tests as a complete safety case.

route selection is an availability/command-age improvement under a shared trusted clock;
diagnostic clear-dwell recovery improves observation correctness, not actuator capability.

function is introduced. Six persistent C stale-delivery collisions remain open because no
fresh request reaches a usable path. All eighteen baseline B/C failures have event evidence.

## Focused FMEA / qualitative fault tree

| Failure/insufficiency | Effect / hazard | Mechanism / evidence | Residual |
|---|---|---|---|
| Old valid primary beats fresh backup | Outdated intent -> HE-01/04 | REC-501 authentic-time selection, unit/system tests | Common key/clock compromise; no overall final-set collision reduction |
| Historical pressure treated as current | Misleading diagnostic -> impaired supervision | REC-502 current observer + clear dwell | Diagnostic recovery is not rescue; DTC remains latched |
| All usable commands withheld/stale | Brake timeout and loss of decel -> HE-04 | Baseline individual failure timelines | Must not accept stale packets merely to improve count |
| Shared Brake ECU/actuator failure | No delivered braking -> HE-01/04 | Final dedicated failure strata, achieved monitor | Backup transport cannot create physical braking |
| Ghost vs uncertain real target | Unnecessary brake or delayed/missed intervention -> HE-01/02 | Five-profile, eight-case SOTIF study | Rejecting uncorroborated data can worsen true-obstacle safety |
| Trusted malicious/incorrect producer | Correct MAC but dangerous intent -> HE-02 | Existing A12/common compromise evidence | Independent intent authority absent |
| Retained state/clock failure | Replay acceptance or unavailability | Explicit memory abstraction / characterization | No tamper-resistant storage/HSM/clock implementation |

Collision top event remains an OR of insufficient usable perception, insufficient generated/
delivered braking, premature release, physical stopping-distance insufficiency and ODD
exclusion. Security adds withholding, state divergence, shared gateway/key failure and
congestion to the delivery/information branches. Harmful unnecessary braking can arise from
perception error, accepted malicious demand or overlong uncertain intervention. Shared clock,
software, scene, keys, ECU and actuator invalidate independent cut-set probability assumptions.
No quantitative failure rates, attack probabilities or risk acceptance are fabricated.

SOTIF studies separate genuine targets/noise, isolated and common ghosts, confidence,
occlusion and fog from explicit malicious-source injection. Temporal filtering counts
acquisitions, not repeated cached cycles; persistent ghosts can still pass. Corroboration
and confidence suppression eliminate some false braking while creating genuine-obstacle
collisions. The 3 m/s² study reduces intensity but can increase impact. No following vehicle
exists, so rear-end harm from false braking is discussed qualitatively, not numerically.
The default is retained because no broadly safe alternative is demonstrated by these data.

TARA remains project ordinal prioritization, not an ISO risk class. The v0.4 structured
workbook is extended by two review threat/diagnostic records; all original residual risks
remain. HMAC authenticates a permitted source under public-fixture assumptions, not true
world state or benign intent. See the assurance case for conditional claims and defeaters.
