# Independent source and evidence audit — before v0.3.0 fixes

The v0.2.0 source, models and raw evidence are retained in a SHA-256 archive under
baseline/v0.2.0. Reproduction runs write only results/v0.3.0/baseline. Historical
measurement files are not revised. The previous release gate is an evidence-integrity
check, not independent engineering approval.

| Finding | Source evidence | Consequence / intended correction |
|---|---|---|
| Seeds vary nominal radar noise only; fault times, geometry, driver and dynamics fixed | RadarModel uses seeded Gaussian samples; runner fixes all other inputs | Distinct noise trajectories are not diverse traffic trials. Add parameter-diverse, declared hold-out scenarios; CIs apply only to a specified modeled sample |
| Plant respects min(request, mu*g); planning uses 4 m/s² regardless of mu | vehicle.py vs ADAS stopping envelope | Braking physics is friction-limited, prediction is not friction-aware. At mu<4/9.81 the stopping assumption fails. Do not feed ground-truth mu into decisions or assert all-weather avoidance |
| Contact tested only at step endpoints; impact at end-of-step | runner.py | Can miss an interior contact or misstate impact time. Add piecewise constant-acceleration minimum/contact analysis accounting for either vehicle stopping |
| Runner integrates one step beyond nominal duration | range(n_steps+1) with integration on final iteration | Stop at horizon before advancing physics |
| Inputs sampled before integration; sensor queue uses sampling timestamps | runner.py/sensors.py | No future truth in current decisions. Camera must preserve delayed sampling timestamp; fusion can align only using measured rate |
| CAN = fixed one-step delay, no contention, software/hydraulic failures absent | InProcessCanBus, BrakeEcu | Timings are model assumptions, not realistic bus guarantees. Add explicit latency/duplicate/intermittent fault study and distinguish actuator failures |
| Accepted-counter progress is not matched to an exact command identity | monitor_feedback, modulo-16 echo | Useful sustained loss detection, not proof of demand delivery, authenticity or applied acceleration |
| Active flag is upstream of tire friction; ack may progress despite physical failure | BrakeStatus/runner | Add independent achieved-deceleration mismatch supervision; acknowledgment cannot stop a broken actuator |
| WARNING can enter BRAKING after speed leaves activation window | evaluate_threat_states orders threat before speed check | Violates ADAS-REQ-004 stated restriction; add boundary regression and correct guard ordering |
| 39 VERIFIED means linked tests passed, not complete requirements satisfied | trace_check loads tagged results; ST-SLICE-003 exercises only S01 | SG-02 confidence/false braking, general ODD and failure containment remain unproven. Report verification scope and residual failures explicitly |
| Existing test supports 4 m/s² planning and nominal S04, not all lead dynamics | UT-V2/ST-V2 cases | Hold-outs must vary friction, gap, lead braking, visibility, target selection and failures |
| State graph matched legal edges, not executable semantics | check_assurance.py | Actual SysML parser/semantic checks and engineering model review are separate obligations |
| Host ctypes wall timing mislabeled ECU timing if generalized | RunResult adas_step fields | Add process CPU call timing; label FFI/host scope, no target WCET claim |

No new ASIL assignment is made. v0.2.0 provisional classifications remain historical
working assumptions, not substantiated automotive allocations. The 20/20 fault collisions
are real within this model. New communication/sensing paths may improve measured scenarios,
but do not demonstrate real-world independent redundancy or backup physical braking.
