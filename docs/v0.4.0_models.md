# Security model assurance

The new genuine SysML v2 model is models/v0.4.0/security.sysml. The official SysML pilot
0.63.1 loads it together with the preserved v0.3 architecture and 44-requirement model.
The security extension models protected PDU fields, command/sensor/status protectors and
verifiers, common key-policy service, separate transport authentication responsibility,
five security requirement allocations/verification relationships and dependencies on
FSR-203 and PER-302. An abstract rejection/resynchronization/unavailable lifecycle is modeled.

Actual parse/semantic output and input SHA-256 hashes are in results/v0.4.0/sysml-validation.log:
zero errors/warnings. A separate unresolved-type model is rejected; the negative-control log
and combined positive model input are preserved. No verification case is executed by the
SysML validator and no invented pass verdict is assigned. Native test results supply external
verification evidence. Name-encoded units, abstract lifecycle and simplified key-policy ports
are incomplete engineering modeling, even when language-valid.

The UML trust-boundary model is parsed/rendered using PlantUML 1.2026.2/Smetana. It makes the
untrusted transport, Python authentication boundary, trusted FFI/native ECUs and common
physical actuation dependency visible. The SysML extension is an abstraction, not exhaustive
wire scheduling, clock/key provisioning, physical redundancy or a formal behavioral-equivalence
proof. The original ADAS-to-Body state path remains authenticated by the implementation; the
extension's detailed port model emphasizes command, sensor and Brake-status responsibilities
rather than claiming complete protocol coverage merely because it parses.

Security trace checking joins threat -> goal -> security requirement -> mechanism/source ->
executed tests -> experiment evidence, and co-engineering case -> affected safety requirement
-> hazardous event -> matched experiment result. Passing link/semantic checks is not a
cybersecurity assurance case or satisfaction of all damage-scenario prevention goals.
