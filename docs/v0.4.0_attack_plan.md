# Isolated attack and verification plan

All injection runs are local queue/object operations; no sockets, CAN devices, real vehicles
or external networks are targeted. TARA specifies attacker access. The following observable
success criteria are evaluated at the relevant layer, not inferred merely from an injected
packet. Decisions, counts, state sequences and safety outcomes are raw JSON/CSV evidence.

| ID | Exact injection / precondition | Success criterion and layer | Expected control boundary |
|---|---|---|---|
| A01 | Spoof plausible radar ghost under unauthorized source/key identity | Sensor ingress delivers spoof and achieved unnecessary braking occurs on a no-target run | Sender policy should reject B/C; raw A has no source authentication |
| A02 | Replay captured command 16 steps old (160 ms); matches modulo-16 alive cycle | Old command passes gateway and, when primary only, native CRC/counter acceptance | B/C age/counter rejection; DoS by replacing fresh demand remains possible |
| A03 | Unauthorized node sends in-range emergency demand with valid CRC | Native accepted malicious demand and achieved braking without a target | Role/key policy, not sender-string trust |
| A04 | Change active/decel, recompute CRC, leave original tag | Native malicious demand accepted/achieved unnecessary braking | MAC integrity; a correctly recomputed CRC alone cannot protect it |
| A05 | Withhold then stream original authenticated packets delayed 200 ms | Stale original reaches native ECU | Maximum age blocks it; withholding can still defeat braking |
| A06 | Authorized freshness state jumps +1000 with valid tags | Availability attack/fault succeeds if valid emergency requests are rejected and vehicle collides | B rejects gap; C authenticates then permits bounded forward recovery |
| A07 | Six high-priority frames/10 ms, bounded 64 queue/four service | Communication delay/drop/pressure; safety consequence separately measured, not assumed | Resource bounds/diagnostic/backup, no crypto availability guarantee |
| A08 | Delay original packet 60 ms (new security cases also 120/200) | Delayed valid command admitted, and any response/separation cost measured | <=100 ms may be intentionally accepted; admission is not necessarily an attack success or safety violation |
| A09 | Duplicate previous command on alternate steps | Duplicate passes gateway/native twice | Monotonic replay check; baseline native alive logic already detects some duplicates |
| A10 | Sender counter rollback in same epoch at 4 s; C retained-epoch restart +200 ms | Old freshness accepted, or rejection causes loss of emergency braking | Reject rollback; pinned B vs explicit next-epoch C. Receiver restart/retention/exhaustion also unit tested |
| A11 | Authorized sensor signs implausible 500 m value | Implausible data used as a valid target; missed braking is a separate safety consequence | MAC alone accepts; fusion/ADAS plausibility must reject |
| A12 | Authorized compromised ADAS signs 9 m/s² demand | Correctly authenticated native demand causes unnecessary braking | Outside authenticity's intent assurance; remains open |

`attack_accepted` is gateway acceptance, not physical attack success. Native attack acceptance
is instrumented only for primary-only configurations where channel attribution is unambiguous.
Sensor attack counts are separate. Message provenance labels affect experiment counters only;
no security decision trusts them. A06/A10/A11 are privileged/fault cases, not outsider tag forgery.
A08's age-tolerated delivery can be correct behavior; a blanket rejected-all-attacks statistic
would be misleading. A12 is expected to remain dangerous under symmetric authentication.

Verification includes public known-answer HMAC vector, valid/modified/unauthorized messages,
length/padding/identity/domain errors, age/counter/epoch boundaries, out-of-order/repeated data,
retained receiver reconstruction, per-producer restart isolation, exhaustion and no state update
on failure. Two Hypothesis properties use 100 generated examples each. The standalone seeded
Python mutation/random harness executes 20,000 parser inputs. None of these proves a zero
attack probability. Native libFuzzer/ASan/UBSan build was attempted but failed because the
installed AppleClang lacks libclang_rt.fuzzer_osx.a; no native fuzz execution is claimed.

Existing 79 functional/safety/SOTIF tests remain active. Eleven initial security tests grew
to twelve after the authenticated-but-implausible sensor case. A backup adapter time-argument
mismatch was exposed and fixed; failed increment log retained. A metrics correction added
achieved unnecessary braking independently of ADAS's own request flag, so a forged native
actuation is not incorrectly counted safe. Sender restart state was isolated per actual
producer rather than sharing a bus epoch; first experiment attempt is retained. No threshold
or key/age/gap policy was tuned against the new held-out outcomes.
