Unchanged baseline reproduced here: 34 C++ tests + 19 pytest tests passed. Six original
scenarios and 16 original speed/friction sweep points rerun at 20 seeds each. Paired extended
evaluation adds 15 fixed boundary/adverse inputs, including low friction and 81 km/h.

Implementation increments retain original TTC functions and threshold tests. TTC-only unit tests
explicitly disable the new envelope; integrated S03 now expects an earlier trigger. S03 no longer
necessarily reaches the emergency flag threshold, so its lamp assertion checks the existing
6 m/s² policy; dedicated BCM emergency-lamp tests are retained. ABI increased to 2 because
configuration and input structures changed; Python bindings verify native version and sizes.
CAN 0x220 bytes 5/6 now carry acknowledgment metadata: all three ECUs require coordinated update.
